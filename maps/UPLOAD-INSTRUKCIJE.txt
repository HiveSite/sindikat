STUDIO83 MAPS - DIREKTAN UPLOAD

1. Raspakuj studio83-maps-ready.zip.
2. Otvori folder studio83-maps-ready.
3. Uploaduj SVE što je unutar njega u root sajta, najčešće public_html/.
4. Obavezno uploaduj:
   - index.html
   - main.js
   - style.css
   - kompletan src/ folder
   - kompletan public/ folder
5. Ne uploaduj samo index.html jer aplikacija koristi module iz src/ foldera.
6. Otvori domen preko HTTPS-a i uradi hard refresh.

POČETNI FAJL:
/index.html

LOKALNI TEST:
python -m http.server 8080
pa otvori http://localhost:8080

NAPOMENA:
Mapa, pretraga, rute i biblioteke zahtijevaju internet konekciju.
