MONTENEGRO TREASURE HUNT - GIT READY

1. Kopiraj cijeli folder u svoj Git repo.
2. Instaliraj Node.js 22 ili noviji.
3. Kopiraj .env.example u .env.
4. Pokreni: node server.mjs
5. Otvori: http://localhost:3000

Test vaučer u development režimu: MTH-TEST-ALL
Admin development pristup je opisan u README.md.

VAŽNO:
- .env se ne commituje.
- data/mth.sqlite se ne commituje.
- Produkcijski server mora imati trajni disk/volume za data folder.
- Prije javnog puštanja promijeni sve tajne i isključi razvojni test vaučer.
